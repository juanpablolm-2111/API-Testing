# API Testing Project – Urban Grocers

## Project Overview

This project focuses on functional API testing of the Urban Grocers REST API. The objective was to verify that different API endpoints returned the expected HTTP status codes and response data according to the API documentation.

Testing was performed using Postman, with Swagger used as a reference to understand the available endpoints, request parameters, expected responses, and error handling.

## API Documentation

[View Urban Grocers API Documentation – Swagger](https://urban-grocers-es.up.railway.app/api/swagger/#/)

## Project Structure

- **Test-Cases/** – Contains test case documentation in PDF and Excel formats.
- **Bug-Reports/** – Contains documented bug reports and testing findings.

## Testing Activities

- Executed HTTP requests to different API endpoints using Postman.
- Validated HTTP status codes and response bodies.
- Verified JSON response structures and data.
- Tested requests with valid and invalid input data.
- Checked API error handling for invalid request structures and data types.
- Compared actual responses against expected results based on the API documentation.
- Documented test cases and bug reports.

## Tools and Technologies

- **Postman** – API request execution and response validation.
- **Swagger UI** – API documentation and endpoint reference.
- **REST API** – API testing.
- **HTTP** – Status code validation.
- **JSON** – Request and response data validation.
- **Microsoft Excel / PDF** – Test case and bug report documentation.
